# 🎯 OPSI 1 ADAPTIVE RECORDING + 3 REPETITIONS GUIDE

## **Apa yang Sudah Diubah?**

Sistem pengambilan data sekarang menggunakan:
- ✅ **Opsi 1 - Adaptive Recording**: Gesture recording akan berhenti otomatis saat stabilisasi
- ✅ **3 Repetisi per gesture** (bukan 5 lagi): Lebih cepat, akan di-augmentasi
- ✅ **Fase-fase yang jelas**: Persiapkan → Check → GO! → Gesture (auto-stop) → Release

## **Timeline Lengkap PER GESTURE**

```
🎬 START RECORDING
   ↓
[0-3 detik]  📍 PERSIAPKAN (GET READY)
   • Letakkan tangan di meja (SANTAI)
   • Jari terbuka penuh (RELAKS)
   • Jangan gerak
   • Sistem: Menghitung mundur 3, 2, 1

   ↓
[3-4 detik]  🔍 CHECK BASELINE (VALIDASI)
   • Tangan masih santai (JANGAN GERAK)
   • Sistem: Membaca nilai sensor baseline
   • Sistem: Menetapkan posisi "normal" untuk kalibrai

   ↓
[4 detik]    🎯 GO! SIGNAL
   • Ini adalah SIGNAL untuk mulai gesture
   • Anda MULAI membuat gesture sekarang

   ↓
[4-7 detik]  ✍️ GESTURE EXECUTION (ADAPTIVE AUTO-STOP)
   • Buat gesture sesuai instruksi (0.5s)
   • Tahan di posisi sempurna (0.5-1.5s)
   • Sistem OTOMATIS DETECT saat stabil
   • Sistem OTOMATIS STOP saat sensor stabil >0.5s
   • Variasi durasi: 0.8-4 detik tergantung durasi gesture
   
   Contoh timeline untuk gesture ANGKA "0":
   [GO!] → [0.2s berbentuk lingkaran] 
         → [0.8s puncak gesture] 
         → [1.5s stabil] 
         → [STOP OTOMATIS] ✓
   Total recording: ~2 detik

   ↓
[7-8 detik]  🔄 RELEASE (LEPAS GESTURE)
   • Perlahan-lahan buka jari kembali NORMAL
   • Tangan kembali santai di meja
   • Sensor kembali ke baseline
   • Durasi: ~1 detik

   ↓
✅ RECORDING SELESAI
   Total waktu per gesture: 7-8 detik (bukan 8-9 detik)
   Time saved: 1 detik × 3 rep = 3 detik per gesture
   Total: 3 detik × 100 gesture = 5 MENIT LEBIH CEPAT!
```

## **Gerakan Tangan yang BENAR**

### **Fase 1: PERSIAPKAN (Santai)**
```
Posisi:
  • Kedua tangan di atas meja
  • Jari-jari terbuka penuh (tidak mengepal)
  • Pergelangan tangan rileks
  • Tidak ada gerakan

Tujuan:
  ✓ Sistem membaca baseline (posisi normal tangan)
  ✓ Validasi sensor working correctly
```

### **Fase 2: GO! (Mulai Gesture)**
```
Apa yang terjadi:
  • Layar akan show "GO!"
  • Ini adalah SIGNAL START

Siapa yang bertindak:
  ➜ ANDA: Mulai membuat gesture sekarang
  ➜ SISTEM: Mulai recording data

Kecepatan:
  • Gesture dibuat dalam 0.2-0.5 detik
  • CEPAT tapi NATURAL (bukan robotik)
```

### **Fase 3: HOLD GESTURE (Tahan)**
```
Apa yang terjadi:
  • Gesture sudah terbentuk (puncak)
  • Anda TAHAN posisi ini

Durasi:
  • 0.5-1.5 detik saja
  • BUKAN lama seperti dulu (2-3 detik)

Sistem:
  • Membaca data gesture
  • Mendeteksi stabilitas
  • OTOMATIS BERHENTI saat stabil
```

### **Fase 4: RELEASE (Lepas)**
```
Apa yang terjadi:
  • Layar show "RELEASE"
  • Anda perlahan membuka jari

Kecepatan:
  • Perlahan (1 detik)
  • BUKAN langsung buka
  • Mirip gerakan "relaxing"

Tujuan:
  ✓ Sensor kembali normal
  ✓ Data "release" tercatat dengan baik
  ✓ Siap untuk gesture berikutnya
```

## **Cara Menggunakan**

### **Step 1: Mulai Recording**
```
1. Click button "START [SPACE]"
2. Layar show "GET READY"  ← Santai, jangan gerak
3. Hitung mundur 3, 2, 1
```

### **Step 2: Fase Persiapkan & Check**
```
1. Layar show "CHECK BASELINE"  ← Masih santai, sensor sedang baca
2. Wait 1 detik
3. Layar show "GO!"  ← NOW MULAI GESTURE!
```

### **Step 3: Buat Gesture**
```
1. LANGSUNG saat GO! - buat gesture CEPAT
2. Tahan posisi sempurna (tulang jari bengkok benar)
3. Tunggu 0.5-1.5 detik hingga stabil
4. Sistem OTOMATIS STOP (tidak perlu Anda hentikan)
```

### **Step 4: Release Gesture**
```
1. Layar show "RELEASE"
2. Perlahan buka jari kembali normal
3. Tangan kembali santai
```

### **Step 5: Lihat Chart & Approve**
```
1. Grafik muncul menampilkan data yang terekam
2. Cek apakah data terlihat benar
3. Click "✓ NEXT / SAVE DATA" untuk simpan
4. Atau click "✗ RETRY RECORDING" untuk ulangi
```

## **Sistem Auto-Stop (Fitur Baru!)**

Gesture recording akan **otomatis berhenti** ketika:

```
✓ Sensor flex stabil selama 0.5 detik
✓ Perubahan minimal antara sample-sample terakhir
✓ Sudah melewati minimum gesture time (0.8s)

Contoh:
• Gesture dibuat: 0.3s
• Tahan posisi: 0.8s (stabil)
• Sistem detect stabil → STOP OTOMATIS ← tidak perlu menunggu timer selesai!
```

**Keuntungan**:
- ✅ Tidak ada "empty holding time"
- ✅ Lebih natural
- ✅ Data lebih bersih

## **FAQ: PERTANYAAN UMUM**

### **Q: Kenapa hanya 3 repetisi saja?**
**A:** 
- 5 repetisi = 40-45 menit untuk 100 gesture
- 3 repetisi = 21-24 menit untuk 100 gesture
- Kemudian gunakan **data augmentation** untuk generate variasi:
  - Rotasi jari (±5°)
  - Time warping (mempercepat/memperlambat)
  - Noise injection (simulasi variasi natural)
  - Mixing samples (blend gesture)
- Total data: 3 repo × 3 augmentation = 9 effective samples per gesture ✓

### **Q: Apakah sistem bisa detect saat saya belum selesai membuat gesture?**
**A:** 
Tidak! Ada minimum gesture time 0.8 detik, jadi:
- 0-0.8s: Sistem TIDAK akan stop (mengumpulkan data)
- 0.8s+: Sistem check stabilitas setiap 0.1 detik
- Saat stabil 0.5s: Baru stop

Ini memastikan gesture sempurna terekam!

### **Q: Bagaimana kalau saya lambat membuat gesture?**
**A:**
- Sistem punya durasi maksimal per kategori (3-4 detik)
- Jadi walau Anda lambat, masih ada waktu
- Tapi usahakan NATURAL & CEPAT seperti gesture asli

### **Q: Apa bedanya dengan sistem lama?**
**A:**

| Aspek | Lama | Baru |
|-------|------|------|
| **Fase** | Prep (3s) → GO! → Record (3-5s) | Prep (3s) → Check (1s) → GO! → Record (adaptive) → Release (1s) |
| **Auto-stop** | Tidak (fixed timer) | Ya (saat stabil) |
| **Release phase** | Tidak | Ya (1s) |
| **Durasi holding** | 2-3s tangan nahan gesture | 0.5-1.5s (natural) |
| **Repetisi** | 5x | 3x |
| **Augmentation** | Tidak | Ya (3x × 3 augment = 9x data) |

## **TIPS & TRICKS**

### **Pro Tips:**
1. ✅ **Gesture konsisten**: Buat gesture yang sama-sama (posisi jari, orientasi tangan)
2. ✅ **Natural speed**: Buat gesture dengan kecepatan alami (bukan super cepat atau super lambat)
3. ✅ **Jangan bergerak ekstra**: Saat "hold" gesture, tahan BETUL-BETUL, jangan gerak
4. ✅ **Relaksasi sempurna**: Di fase persiapkan, benar-benar santai, jangan tegang

### **Jangan:**
1. ❌ Membuat gesture robotik/aneh (gunakan gerakan asli)
2. ❌ Gerak ekstra di saat "hold" (data jadi berantakan)
3. ❌ Tidak follow timeline (persiapkan → check → GO!)
4. ❌ Terburu-buru (natural > cepat)
